📋 Supabase SQL Tablo Kurulumu

Eğer Supabase SQL Editor'da tabloları henüz oluşturmadıysan, aşağıdaki SQL kodunu kopyalayıp Supabase panelinde çalıştır:

-- 1. Ürünler Tablosu create table if not exists products ( id text primary key, name text not null, qty integer not null default 0, price numeric(10,2) not null default 0, cost numeric(10,2) not null default 0, emoji text default '🎨', created_at timestamptz default now() ); -- 2. Satışlar Tablosu create table if not exists sales ( id text primary key, product_id text references products(id) on delete set null, product_name text not null, price numeric(10,2) not null default 0, cost numeric(10,2) not null default 0, payment text not null, qty integer not null default 1, at timestamptz not null default now(), status text not null default 'completed' ); -- 3. Row Level Security & Anon İzinleri alter table products enable row level security; alter table sales enable row level security; create policy "Anon Products All" on products for all using (true) with check (true); create policy "Anon Sales All" on sales for all using (true) with check (true); -- 4. Supabase Realtime İzinleri alter publication supabase_realtime add table products; alter publication supabase_realtime add table sales;
